# AI Resume Assistant

An AI-powered resume assistant that helps users tailor their resumes to specific job descriptions while ensuring every suggested skill and experience is truthful and supported by evidence.

## Features (Planned)

- Upload Job Description
- Upload Resume
- Extract Keywords
- ATS Compatibility Score
- Skill Gap Analysis
- Truthfulness Checker
- AI Resume Generator
- Resume PDF Export
- Interview Question Generator

## Tech Stack (Planned)

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask (or FastAPI)

### Database
- SQLite
- MySQL

### AI
- OpenAI API (or another LLM API)
- Prompt Engineering
